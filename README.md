# Primitive DB

Простая консольная база данных на Python, разработанная в рамках учебного проекта.

## Установка
Для установки зависимостей и настройки окружения выполните:
```bash
make install

## Управление таблицами
- `create_table <имя> <столбец:тип> ...` — создать таблицу.
- `list_tables` — показать список таблиц.
- `drop_table <имя>` — удалить таблицу.

## CRUD-операции
- `insert <имя_таблицы> <значение1>,<значение2>...` — добавить запись (ID генерируется автоматически).
- `select <имя_таблицы>` — вывести все записи.
- `select <имя_таблицы> where <столбец> = <значение>` — вывести отфильтрованные записи.
- `update <имя_таблицы> set <столбец> = <значение> where <столбец> = <значение>` — обновить записи.
- `delete <имя_таблицы> where <столбец> = <значение>` — удалить записи.
- `help` — показать справку.
- `exit` — выйти из программы.

## Дополнительные возможности
- **Обработка ошибок**: Все ошибки (неверный тип данных, несуществующая таблица, синтаксические ошибки) перехватываются декоратором `handle_db_errors`. Программа не падает, а выводит понятное сообщение пользователю.
- **Подтверждение опасных действий**: При удалении таблицы или записей программа запрашивает подтверждение (y/n) с помощью декоратора `confirm_action`.
- **Замер времени**: Декоратор `log_time` выводит время выполнения для операций `insert` и `select`.
- **Кэширование (замыкание)**: Результаты одинаковых запросов `select` кэшируются функцией `create_cacher`. При повторном запросе данные берутся из кэша, что ускоряет работу. Кэш автоматически очищается при любых изменениях данных.
