\# Primitive DB



Простая консольная база данных на Python.



\## Управление таблицами

\- `create\_table <имя> <столбец:тип> ...` — создать таблицу.

\- `list\_tables` — показать список таблиц.

\- `drop\_table <имя>` — удалить таблицу.



\## CRUD-операции

\- `insert <имя\_таблицы> <значение1>,<значение2>...` — добавить запись (ID генерируется автоматически).

\- `select <имя\_таблицы>` — вывести все записи.

\- `select <имя\_таблицы> where <столбец> = <значение>` — вывести отфильтрованные записи.

\- `update <имя\_таблицы> set <столбец> = <значение> where <столбец> = <значение>` — обновить записи.

\- `delete <имя\_таблицы> where <столбец> = <значение>` — удалить записи.

\- `help` — показать справку.

\- `exit` — выйти из программы.
