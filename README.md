# Primitive DB

Простая консольная база данных на Python.

## Управление таблицами
- `create_table <имя> <столбец:тип> ...` — создать таблицу.
- `list_tables` — показать список таблиц.
- `drop_table <имя>` — удалить таблицу.

## CRUD-операции
- `insert <имя_таблицы> <значение1>,<значение2>...` — добавить запись (ID генерируется автоматически).
- `select <имя_таблицы>` — вывести все записи.
- `select <имя_таблицы> where <столбец> = <значение>` — вывести отфильтрованные записи.
- `update <имя_таблицы> set <столбец> = <значение> where <столбец> = <значение>` — обновить записи.
- `delete <имя_таблицы> where <столбец> = <значение>` — удалить записи.
- `help` — показать справку.
- `exit` — выйти из программы.
